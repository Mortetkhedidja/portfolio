موقع Portfolio متعدد الصفحات — Khedidja Mortet

طريقة الفتح:
1) فكّي ضغط الملف ZIP إن كان مضغوطًا.
2) افتحي مجلد khedidja-portfolio.
3) اضغطي مرتين على index.html لفتح الصفحة الرئيسية في المتصفح.
4) من الصفحة الرئيسية اضغطي Explore my projects / اكتشف مشاريعي.
5) اضغطي على عنوان أي مشروع لفتح صفحة تفاصيله.

مهم:
- صورة Stroke Emergency Response System توضع باسم medconnect.png.
- صورة MiroudMed توضع باسم medical-imaging.png.
- إذا لم تضعي صورة، سيظهر اسم المشروع بدلًا منها.
- يمكنك فتح الملفات وتعديلها باستخدام Sublime Text.
- لا تحذفي مجلد css أو js أو projects أو portfolio لأنها ضرورية لعمل الموقع.
- الموقع ثنائي اللغة: زر العربية / English في أعلى الصفحات.
- رابط OMEGA في GitHub مؤقتًا يفتح قائمة مستودعات GitHub العامة لأن رابط مستودعه المحدد غير مؤكد.
